# BetterActivity

[English](README_EN.md) · 中文

版本 0.2.0，为原版 DSH 0.2.2-rc.2 提供近期活动浮层。用户安装不需要任何宿主补丁或源码构建。

## 使用

入口在侧栏底部：展开时显示铃铛和“查看活动”，收起时显示铃铛。Ctrl+Alt+U 切换浮层；macOS 使用 Command+Option+U。关闭按钮、Escape 或点击外部可关闭。当前聊天和普通列表保持挂载，浮层在当前窗口保存开关、分页与滚动位置。

列表显示标题、淡色项目名、两行公开助手摘要和状态。等待处理、未读失败、运行中、未读完成依次优先，其余按客户端本地日期分组。流式摘要更新不触发行重排。空白、已归档会话隐藏，子任务只归入有效且未归档的普通父会话；点击待处理条目可打开真正需要操作的子会话。

点击条目使用原生导航并关闭浮层；右键菜单复用原生操作。原生全局搜索继续使用原功能，获得焦点时活动浮层关闭。本插件不增加搜索框或关键词筛选。

## 已读与数据

自动已读要求当前会话在前台、窗口可见且未被活动浮层、其他模态界面或全屏右栏遮挡，并且原生正文时间线已经发布对应结束事件。不会用运行结束信号或延时猜测正文已到达。“全部标为已读”只提交当前列表已观察到的结果版本；运行中和待处理条目继续保留。

已读状态保存在 better_activity 存储域，升级保留 installedAt 和每个会话的已读位置。同一实例的多个窗口同步，刷新、重启后保留；首次安装前的历史完成项默认已读。独立实例之间没有云同步。写入失败不清除未读，断连保留列表并提供重试。

摘要复用 betterActivity 投影，默认最多 240 个 Unicode 码点，只取公开助手文字，不包含思考或工具原文。后台分批恢复历史，不逐行打开完整对话；初次加载大量历史时摘要会逐渐补齐。Host 的 previewCodePoints、previewIntervalMs、hydrateBatchSize 默认分别为 240、100、50，允许 1–100000 的整数。

## 安装与卸载

要求原版 DSH 0.2.2-rc.2 与 Node.js >=24.9.0。使用所用运行时的 CLI 安装预构建包，不运行 git apply：

```sh
dsh plugin --profile web add /path/to/dsh-better-activity-0.2.0.tgz
```

桌面端通过自身插件管理安装同一 tgz。安装后刷新界面。本轮完整验收在官方 Web 运行时完成；Windows 桌面界面尚未完成本轮复验。

卸载使用：

```sh
dsh plugin --profile web remove dsh-better-activity
```

卸载移除入口与浮层，已读记录保留。0.1.3 升级到 0.2.0 不迁移已读或摘要格式。旧开发环境已有的源码补丁不必自动回滚；其他插件可能仍依赖它们。

本包不依赖 BetterClassifier，也不占用它的列表位置。BetterClassifier 自己的宿主要求由它负责，不能把它的补丁要求算到 BetterActivity 上。兼容记录见 [compatibility.json](compatibility.json)。

## Model Experience

插件不修改提示词、工具、模型请求、工作目录或历史消息，不调用模型生成摘要，不改变上下文或 KV cache。
