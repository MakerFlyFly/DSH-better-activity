## 审查与限制

子代理复核未确认产品代码的高、中、低缺陷。本轮修正了验证设施的问题：交互样例原先先手工写入第 1 回合，再让已创建的 Agent 原生运行，造成重复回合号。原版正确拒绝该非法日志。已保留诊断证据，交互样例现全部通过原生 `prompt` 生成事件，并在新隔离数据复验；没有据此修改活动产品代码。静态历史样例不再交给同一 Agent 继续运行。

原版 DSH 明确禁止受委派子任务调用用户提问（`DELEGATED_CALLER`），并限制子任务扩大审批权限。因此真实子任务验证覆盖运行、汇总、跳转及归档；待处理子会话的导航分支由确定性 UI 测试覆盖。普通会话的提问和审批已实际操作。

Windows 桌面复验未完成：隔离开发壳曾出现主进程 `EPIPE`，初步指向启动父进程退出后的日志管道。该桌面启动问题未修复，相关测试进程已关闭；不声称验证了官方签名安装程序，也不以它阻塞本轮 Web 交付。本记录覆盖本地 Windows 上的 Web、构建与测试验证；推送后的远程 CI 结果以 [GitHub Actions](https://github.com/MakerFlyFly/DSH-better-activity/actions/workflows/ci.yml) 为准。
